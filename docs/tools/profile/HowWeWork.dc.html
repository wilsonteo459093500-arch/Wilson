How the work is held

Four sign-offs between your drawing and your handover.

Production starts only after you have signed the detailed drawings. The project closes only after you have checked the installation against the handover list. Every payment sits behind something you already approved.

01 Site measurement Measured on site, not taken from the developer’s plan.
02 Drawing sign-off You approve the detailed drawing before anything is cut.
03 Pre-delivery inspection Checked before it leaves the factory. It does not ship if it fails.
04 Installation QC Our own installation team, checked against the handover list.
